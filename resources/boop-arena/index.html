# BoopArena BoopArena is a standalone Minecraft arena minigame centered around knockback-based combat, randomized abilities, and player scoring. Players compete to knock opponents out of a designated arena while maintaining their own position. The plugin provides configurable arena management, player statistics, ability controls, and PlaceholderAPI integration, making it suitable for standalone servers and larger minigame networks. ## Features - **Ability System:** Nine unique abilities, including Dash, Teleport, Sonic Boom, Pull, Anchor, Wall, Ghost, Speed Boost, and Swap. - **Randomized Abilities:** Players receive a randomly selected enabled ability upon entering the arena. - **Knockback-Based Combat:** Boop sword hits use configurable minimal damage while preserving knockback mechanics. - **Scoring System:** Players earn points for knocking opponents out of the arena. - **Arena Time Tracking:** Tracks how long players remain in the arena. - **Persistent Statistics:** Saves player points and personal best times across server restarts. - **WorldGuard Integration:** Uses a configurable WorldGuard region to determine arena boundaries and player entry. - **Configurable Abilities:** Individual abilities can be enabled or disabled through the configuration file. - **Custom Return Location:** Provides players with a return prompt following elimination. - **PlaceholderAPI Integration:** Supports displaying player statistics and leaderboard information in compatible plugins. - **Plugin Lifecycle Support:** Handles cleanup of timers, arena state, temporary items, and registered expansions when disabled. - **Standalone Operation:** Does not require HostCore, proxy integrations, or network-specific functionality. ## Requirements - Paper or Spigot - WorldGuard - PlaceholderAPI *(optional)* ## Installation 1. Download the BoopArena plugin jar. 2. Place it into your server's `plugins` directory. 3. Ensure WorldGuard is installed. 4. Start your server to generate the configuration. 5. Configure your arena region and return location. 6. Restart your server or run `/boop reload`. ## Configuration BoopArena provides configuration options for: - Arena region name - Return teleport location - Ability availability - Placeholder compatibility - Other gameplay settings ## PlaceholderAPI BoopArena provides placeholders for arena statistics, including current arena time, personal best time, points, and leaderboard information. Additional compatibility aliases are available for existing HostCore placeholder names. ## Commands `/boop reload` — Reloads the plugin configuration. `/boop return` — Returns an eliminated player to the configured location. --- BoopArena is designed to provide a straightforward, configurable arena experience with minimal setup and support for existing server plugins.
