HeadHunt Skript - One-Time Reward System With Many Possibilities HeadHunt is a lightweight and highly configurable collectible system for Minecraft servers. Hide heads throughout your world and reward players for finding them all. Perfect for hubs, RPG servers, SMPs, Lifesteal servers, seasonal events, and community challenges. Players can track their progress using /headhunt, while administrators can easily create, remove, teleport to, and reset collectible heads in-game. Features Collectible head system. Fully configurable rewards. Individual player progression tracking. Supports both online and offline player resets. Automatically prevents players from collecting the same head twice. In-game management commands. Tab completion support. Lightweight and easy to configure. Uses UUID-based player data. Suitable for permanent or seasonal events. Commands Player Commands /headhunt - View your current progress. Admin Commands /headhunt set - Register a new collectible head. /headhunt remove - Remove a registered head. /headhunt tp - Teleport to a registered head. /headhunt list - View all registered heads. /headhunt reset - Reset a player's progress. /headhunt resetall - Reset everyone's progress. Permissions headhunt.admin - Access to all administrative commands. How It Works Simply place player heads around your server and register them using /headhunt set . When players discover a head, it is permanently recorded and cannot be collected again unless their progress is reset. Once all collectible heads have been found, players can automatically receive configurable rewards such as: Crate Keys Credits Custom Items Economy Rewards Console Commands And more! The default configuration rewards players after finding all 25 heads, but the system can easily be modified to fit your server's needs. Whether you're creating a scavenger hunt, seasonal event, or permanent collectible system, HeadHunt provides a simple and professional solution that's ready to use out of the box.
