# Stream Announcements Give your server's media creators an easy way to announce when they go live! Stream Announcements allows authorized players to broadcast their YouTube or Twitch streams directly in Minecraft chat. Announcements include a clickable link that sends players straight to the creator's stream. ## Features - YouTube stream announcements - Twitch stream announcements - Clickable stream links in chat - Hover text on stream links - Separate permissions for YouTube and Twitch creators - Basic link validation to prevent incorrect platform links - Server-wide stream announcements - Custom colored announcements for each platform - Built-in command help - Tab completion for `/stream` - Admin toggle to temporarily disable all stream announcements ## Commands `/stream youtube ` Announces a YouTube stream to the entire server. `/stream twitch ` Announces a Twitch stream to the entire server. `/stream close` Allows authorized staff to disable or re-enable stream announcements. `/stream` Displays the available stream commands. ## Permissions `stream.youtube.media` Allows a player to announce a YouTube stream. `stream.twitch.media` Allows a player to announce a Twitch stream. `stream.close` Allows staff to enable or disable the stream announcement system. ## How It Works When a media creator goes live, they can simply run: `/stream youtube ` or `/stream twitch ` The server will broadcast their stream to every online player with a clickable **CLICK HERE** button. The Skript also checks that the submitted link matches the selected platform before allowing the announcement. Perfect for servers with YouTubers, Twitch streamers, media ranks, or creator programs.
