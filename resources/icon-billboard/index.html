# IconBillboard IconBillboard is a Paper plugin that allows server owners to create interactive, map-based billboards for displaying advertisements, images, animations, and video content directly in Minecraft. Designed for server lobbies, networks, and community spaces, IconBillboard provides a flexible advertising system with support for rotating media, clickable interactions, live streams, and audio playback. ## Features - **Dynamic Billboards** — Create custom billboard displays using item frames and maps. - **Image Support** — Display images directly on in-game billboard displays. - **GIF Support** — Animate media directly within your billboards. - **Video Support** — Display MP4 and other supported video media. - **Live Streams** — Support for Twitch streams and direct HLS streams. - **Automatic Media Rotation** — Cycle through multiple advertisements on a configurable schedule. - **Interactive Billboards** — Allow players to click displays to trigger commands or view additional information. - **Clickable Links** — Provide clickable URLs through billboard interaction. - **Audio Support** — Extract and play audio from supported media using custom Minecraft sounds and resource packs. - **Local & Remote Media** — Load media from local files or supported URLs. - **Configurable Displays** — Customize billboard behavior, media duration, cycling, and interactions. - **Easy Management** — Create, edit, manage, and remove billboards through simple commands. ## Commands | Command | Description | |---|---| | `/ib wand` | Obtain the billboard selection wand. | | `/ib create ` | Create a billboard using selected positions. | | `/ib addmedia ` | Add media to a billboard. | | `/ib show ` | Display a specific media item. | | `/ib cycle ` | Toggle automatic media cycling. | | `/ib click ` | Configure billboard interactions. | | `/ib setinfo ` | Set the information displayed when clicked. | | `/ib removemedia ` | Remove a media item. | | `/ib delete ` | Delete a billboard. | | `/ib list` | View existing billboards. | | `/ib reload` | Reload the plugin configuration. | ## Requirements - Paper - FFmpeg *(for video, stream, and audio processing)* - yt-dlp or Streamlink *(for supported stream resolution; can be automatically downloaded on supported systems)* IconBillboard is ideal for server advertisements, partner promotions, announcements, storefront displays, community showcases, and interactive lobby environments. Used by **PulsedMC** at `play.pulsedmc.net`.
